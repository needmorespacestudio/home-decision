# Home Decision — การทดลอง Private Beta แบบมีผู้ดูแล

อัปเดต 8 ต.ค. 2026 · เป้าหมาย: Home Decision ช่วยตัดสินใจได้ดีกว่าการเข้าเว็บร้านค้าแล้วกรองสินค้าเองหรือไม่?

เริ่มกลุ่มเล็ก 5 คนเพื่อหาจุดติดขัด แล้วขยายรวมเป็น 20–50 คนที่มีโจทย์เลือกแอร์ในบ้านจริงเมื่อแก้ปัญหาหลักแล้ว ไม่เพิ่มความซับซ้อนสูตรและไม่ขยายหมวดก่อนมีหลักฐานจากกลุ่มนี้ การทดลองนี้วัดความเข้าใจและคุณค่าของคำแนะนำ ไม่ใช่รับรองความถูกต้อง HVAC หรือประสิทธิภาพติดตั้ง

## หนึ่งครั้ง 15–20 นาที

1. ขอความสมัครใจในการทดลองและเก็บสถิติแบบไม่ระบุตัวตน ให้ผู้ใช้ถอนตัวหรือไม่ส่งไฟล์ได้ ใช้รหัส P01 เป็นต้นในบันทึกผู้ดูแล แยกรายชื่อ/ช่องทางติดต่อออกจากไฟล์ผล
2. ก่อนใช้ ถามว่ากำลังตัดสินใจอะไร มีตัวเลือกในใจหรือยัง และมั่นใจแค่ไหน (1–5) ไม่บันทึกที่อยู่ รูปบ้าน หรือข้อมูลสุขภาพ
3. ให้ผู้ใช้ลองโจทย์เดียวกันบนเว็บร้านค้าที่เขาใช้จริงกับ Home Decision สลับลำดับสองเว็บระหว่างผู้ทดสอบ ไม่ช่วยบอกคำตอบ เวลาเว็บละไม่เกิน 5 นาที บันทึกว่าได้ข้อสรุปหรือยังและเหตุผล
4. บน Home Decision ใช้หน้าใหม่ต่อหนึ่งผู้ทดสอบ ทำหนึ่ง flow ต่อไฟล์ ให้ผู้ใช้เล่าภายใน 2 นาทีว่าแนะนำกี่เครื่อง แบบไหน เพราะอะไร และต้องตรวจหน้างานอะไร หากระบบให้สำรวจหน้างาน การเข้าใจว่าจะถามช่างอะไรนับเป็นผลที่มีประโยชน์ แต่ไม่ใช่เลือกเครื่องสำเร็จ
5. ให้เปิดรุ่น/เว็บทางการ ดูข้อแลกเปลี่ยน และลองส่งออก Decision Brief หรือข้อความถามร้าน ใบเสนอราคาทดสอบให้ใช้ข้อมูลสมมติ ระบบยังไม่อ่าน PDF อัตโนมัติ
6. ให้คะแนน ช่วยมาก / พอใช้ / ยังไม่ช่วย พร้อมเหตุผล แล้วเปิด “ร่วมทดสอบว่าช่วยตัดสินใจได้จริงไหม?” ตอบผลหลังใช้งานและเปรียบเทียบเว็บร้านค้า หากไม่ได้ลองจริงให้เลือก “ยังไม่ได้ลอง”
7. ผู้ใช้กด “บันทึกผลการทดลองไว้ในเครื่อง” ตรวจว่าไฟล์ดาวน์โหลดสำเร็จก่อนปิดหน้า ผู้ใช้เลือกส่งไฟล์ให้ผู้ดูแลเอง ไม่มีการส่งจากเว็บอัตโนมัติ ห้ามนำไฟล์ QA สมมติมารวมกับผลจริง
8. ผู้ดูแลบันทึกเวลา ข้อสรุปก่อน/หลัง ความมั่นใจ และจุดที่ต้องช่วยลงตาราง ไม่มีชื่อ/ข้อมูลห้อง/Quote จริง ผลที่คาดเดาเองให้เว้นว่าง

## เก็บและสรุปผล

เก็บไฟล์ส่งออกในโฟลเดอร์ส่วนตัวที่ผู้ดูแลเข้าถึงเท่านั้น แยก synthetic QA ออก ไม่ commit ผลจริงลง GitHub เก็บไฟล์ดิบไม่เกิน 90 วันหลังจบรอบ จากนั้นลบหรือขอความยินยอมใหม่สำหรับการใช้ต่อ หากผู้ทดสอบขอถอนข้อมูล ผู้ดูแลลบไฟล์ตามรหัสในบันทึกของตน

`python scripts/beta_summary.py /path/to/voluntary-exports --output /path/to/BETA_BATCH_SUMMARY.json`

ส่งออกซ้ำจากหน้าเดียวกันจะใช้ export_id เดิม ตัวสรุปเลือกไฟล์ใหม่ล่าสุด ไม่บวกซ้ำ ไฟล์ที่มีหลาย flow ยังนับสถิติการใช้ได้ แต่ไม่เข้าฐานเปรียบเทียบคำตอบผู้ใช้ซึ่งเป็นของ flow ล่าสุด ไม่มี persistent identity จึงผู้ดูแลต้องกันคนเดิมและไฟล์สมมติเอง

ดูจำนวนผู้ที่ลองทั้งสองเว็บจริงเป็นฐาน เทียบ better / same / worse แยก not_tried และผู้ไม่ตอบ เก็บจำนวนผล decided / shortlist / survey / unclear แยกกัน อย่าเรียก engagement ว่าซื้อแล้ว อย่านำสถิติชุดนี้ไปทำ Popular Choice หรือ KPI รายเดือน

## ตัดสินหลังรอบแรก

เกณฑ์นี้เป็นเกณฑ์ทดลองที่กำหนดก่อนเห็นผล ไม่ใช่ข้อเท็จจริงหรือ industry benchmark:

- หาก ≥70% ของผู้ที่ลองทั้งสองเว็บจริงรายงานว่าช่วยดีกว่า และส่วนใหญ่เล่าข้อสรุป/ข้อแลกเปลี่ยน/สิ่งที่ต้องตรวจได้โดยไม่ช่วย: ขยายรอบถัดไปพร้อมตรวจความแม่นกับผู้เชี่ยวชาญ
- หาก 40–69%: แก้จุดสับสนที่ซ้ำมากที่สุด แล้วทดสอบรอบใหม่ ยังไม่ขยายหมวด
- หาก <40% หรือคนส่วนใหญ่บอกว่าเหมือน filter แต่ถามมากกว่า: ทบทวนคุณค่าที่ให้ โดยเน้นการแบ่งเครื่อง เหตุผลและ Quote แทนเพิ่มคำถาม/สูตร
- หากพบคำแนะนำเสี่ยง: หยุดใช้เส้นทางนั้น ให้ผู้เชี่ยวชาญตรวจ แก้และทดสอบก่อนกลับมาทดลอง

ตัวอย่างเล็กไม่ยืนยันตลาด รายงานจำนวนจริงควบคู่ทุกเปอร์เซ็นต์ ไม่มีผู้ใช้จริงถูกเชิญหรือส่งข้อความโดยงานพัฒนานี้ การจัดผู้ทดสอบและการตรวจ HVAC ต้องมีคนทำจริง
